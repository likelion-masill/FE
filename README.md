# 🏘️ Masill(마실)

**지역 행사와 사람을 연결하는 실시간 로컬 커뮤니티 플랫폼, 마실**

**2025.08**

---

## ✏️ 프로젝트 요약

지역에는 다양한 축제, 플리마켓, 봉사활동, 소상공인 이벤트가 열리지만 정보를 한곳에서 확인하기 어렵고, 행사에 참여하더라도 같은 관심사를 가진 사람들과 자연스럽게 교류할 기회는 많지 않습니다.
또한 동네 상권에서 진행하는 단기 이벤트는 홍보 채널이 부족하여 지역 주민들에게 알려지기 어려운 문제가 있습니다.
마실은 지역 행사 정보를 한곳에서 제공하고, 게시글마다 소모임과 실시간 채팅 기능을 제공하여 지역 주민들이 자연스럽게 소통하고 새로운 관계를 형성할 수 있는 로컬 커뮤니티 서비스를 제공합니다.

---

### 핵심 기술

**React · JavaScript · Spring Boot · WebSocket · MySQL· OpenAI API**

---

### 기대효과

지역 주민들이 행사 정보를 단순히 확인하는 것을 넘어, 관심사가 같은 사람들과 자유롭게 소통하고 함께 참여할 수 있는 새로운 지역 커뮤니티 문화를 제공합니다.
또한 소상공인의 다양한 이벤트를 쉽게 홍보할 수 있는 공간을 제공하여 지역 경제 활성화에도 기여하는 것을 목표로 합니다.

---

## ✨ 핵심 기능

### 1. 지역 기반 행사 탐색

- 지역별 행사 및 이벤트 조회
- 검색, 카테고리, 필터 기능 제공
- AI 추천을 통한 맞춤형 행사 추천

### 2. 게시글 기반 소모임

- 게시글마다 소모임 생성
- 관심사가 같은 사람들과 자유로운 모임 구성
- 댓글을 통한 커뮤니티 형성

### 3. 실시간 채팅

- WebSocket 기반 실시간 채팅
- 소모임 전용 채팅방 제공
- AI 추천 채팅방 기능 제공

### 4. AI 게시글 요약

- AI를 활용한 게시글 핵심 내용 요약
- 긴 게시글도 빠르게 확인 가능

### 5. 회원 시스템 및 마이페이지

- 회원가입 및 로그인
- 프로필 이미지 및 닉네임 변경
- 작성한 게시글 및 관심 목록 관리
- 사장님 인증 기능

---

## 👨‍💻 담당 역할

- 로그인 및 회원가입 UI/UX 구현
- 메인, 검색, 게시글 상세, 마이페이지 UI 구현
- WebSocket 기반 실시간 채팅 UI/UX 구현
